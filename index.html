鍵盤快捷鍵

A / ← 上一張影像
D / → 下一張影像
F 切換全螢幕模式
R 重設 Window Width / Level
Space + 拖曳 平移影像 (Pan)
Backspace / Ctrl+Z 刪除上一個 ROI (復原)
Delete 清除全部 ROI
